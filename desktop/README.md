# Desktop launcher

`st.desktop` matches the default X11 WM_CLASS (`st-256color`) so GNOME Shell
groups windows under the `st` launcher and offers Add to Favorites. The launch
path is replaced with the installation prefix; it does not depend on the
desktop session's PATH. Explicit `st -c` overrides use a different window class.

`st.svg` is the unmodified official logo downloaded on 2026-11-12 from
https://st.suckless.org/st.svg (linked at https://st.suckless.org/).
