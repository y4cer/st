The expansion caught three production defects now covered by focused tests:

- Resize clearing read uninitialized wide-cell flags and could erase the preceding
  character. Newly allocated cells are initialized before clearing.
- Large CSI parameters overflowed integer coordinates. Parsing and coordinate
  arithmetic now saturate safely.
- Negative edit counts could reach clearing with reversed boundaries and erase
  cells. Zero-length operations return early and negative ECH is ignored.

No crashes, sanitizer diagnostics, timeouts or adapter gaps are baseline failures.
Every C build uses `-Wall -Werror -Wpedantic`. Local verification commands:
`make test`, `make test-sanitize`, and `git diff --check`; system development headers
were supplied from the extracted Ubuntu packages documented in work memory.
